# PRD — 요구사항 정의서 (Product Requirements Document)

## 프로젝트명
YouTube Native + High-End Insight Ver 3.0 (Next.js 리팩토링)

## 프로젝트 개요
YouTube 검색을 API 네이티브 수준에서 제어하고, **채널 평소 성과 대비 얼마나 터졌는지**를 기준으로 영상을 발굴하는 Next.js 기반 분석 웹앱.

## 핵심 타겟
- YouTube 크리에이터 및 콘텐츠 분석가
- 콘텐츠 마케팅 담당자
- 초보 사용자 (UI 단순화)

## 주요 기능 (MVP Scope)
1. YouTube API 필터 완전 매핑 (order, publishedAfter, videoDuration)
2. 검색 깊이 선택 (50/100/200) + 할당량 비용 표시
3. 클라이언트 정렬 (성과배수, 조회수, 일평균 조회수, 좋아요율, 구독자수, 최신순)
4. 성과 지표 계산 및 시각화
5. 카드형/리스트형 전환 UI
6. Dark Mode + 반응형 (모바일 드로어)
7. 보관함 — 검색 결과 자동 저장(브라우저 localStorage, 재방문 시 할당량 0), 복사한 프롬프트·LLM 분석 결과 보관

## 성과 지표 정의

| 지표 | 정의 | 역할 |
|---|---|---|
| **성과배수** | 조회수 ÷ 같은 채널·같은 포맷(Shorts/롱폼) 최근 영상의 중앙값 (본 영상·라이브·예정 제외) | 주지표. "이 채널 평소 대비 몇 배". 라이브·예정은 측정불가 |
| 일평균 조회수 | 조회수 ÷ max(1, 업로드 경과일) | 오래된 영상의 상위 독식 교정 |
| 일평균 배수 | 일평균 조회수 ÷ 같은 채널·같은 포맷 동료의 일평균 중앙값 | 누적 배수의 짝. 검색 결과 영상은 동료보다 수년 오래돼 누적 배수가 유리하다 |
| 좋아요율/댓글율 | 좋아요(댓글) ÷ 조회수 | 알고리즘 노출과 실제 반응 구분 |
| 구독자 대비 | 조회수 ÷ 구독자수 | 참고값 |

구독자수를 주 분모로 쓰지 않는 이유: 채널이 숨기면 값이 아예 오지 않고,
1,000명을 넘으면 유효숫자 3자리로 반올림된다(123,456 → 123,000).
**계산 불가는 0이 아니라 '측정불가'로 표시한다.**

## 사용자 흐름
검색어 입력 + 검색 깊이 선택 → 성과배수 순 결과 확인 → "시장 분석 복사"·"썸네일 시트 복사"를 LLM에 붙여넣기 → (개별 영상은 "AI분석", 자막을 붙여넣으면 대본 구조까지) → YouTube 원본 이동. 보관함(/history)에서 지난 검색·출력 재조회
