## C. 제품 제약 (해결 불가 — 숨기지 말 것)

- **타인 영상 자막**: `captions.download`는 소유자 OAuth 필수. 비공식 엔드포인트는 ToS §5.B 위반 소지. 공개 제품이면 **사용자 붙여넣기 입력란**만 안전.
- **CTR·노출수·시청 지속률**: 채널 소유자 전용(Analytics API).
- **알고리즘 노출량**: 조회수에서 분리 불가.
- **썸네일 이미지**: 클립보드 텍스트로는 안 넘어감. `i.ytimg.com`은 CORS 헤더가 없어 클라이언트 캔버스 합성도 불가 → 서버 프록시가 있어야 함.

## D. 보류 설계 (B3 실측 결과가 필요하다고 말하기 전까지)

| 안 | 요지 | 상태 |
|---|---|---|
| 채널 uploads로 포맷 분리 정규화 | B1 해결. 채널당 2 units, 검색 버킷과 무관. | **가장 유력. B3 후 착수 후보 1순위** |
| 썸네일 컨택트시트 → 클립보드 이미지 | 서버 프록시 `/api/thumbnail` + 캔버스 격자 합성 + `ClipboardItem(image/png)`. 라벨이 프롬프트 표 행 번호와 일치. | 유력, 논쟁 없음 |
| 자막 붙여넣기 입력란 | 0원, 법적 위험 0. 깊게 볼 1~2편용. | 유력 |
| 댓글 수집 (`commentThreads.list` 1 unit) | 유일한 자연어 시청자 반응 데이터. | 검토 |
| 시간 창 표본 (`order=date` + `publishedBefore/After`) | 성과 랭킹 제거된 키워드 표본. **단**: 창 밖 relevance 집합과는 나이 분포가 달라 그대로 비교 불가, `order=date`는 스팸 편향, `publishedBefore` 무시 버그 보고([245018357](https://issuetracker.google.com/issues/245018357)) 있음. | 보류 |
| 채널 uploads로 키워드 표본 확장 | 키워드가 구체적일수록 채널 카탈로그 내 비중이 0에 수렴하고, 검색이 on-topic 영상을 이미 걷어가 잔량이 더 적다. | **철회** |
| 특징 집계를 LLM에서 코드로 이관 | n≥수백일 때 의미. 현재 n=50에서는 거짓 정밀도 위험. | 표본 확보 후 |
| LLM API 앱 내 연동 | 사용자가 클립보드 유지를 선택. | 보류 |
