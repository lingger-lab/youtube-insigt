## C. 제품 제약 (해결 불가 — 숨기지 말 것)

- **타인 영상 자막**: `captions.download`는 소유자 OAuth 필수. 비공식 엔드포인트는 ToS §5.B 위반 소지. 공개 제품이면 **사용자 붙여넣기 입력란**만 안전.
- **CTR·노출수·시청 지속률**: 채널 소유자 전용(Analytics API).
- **알고리즘 노출량**: 조회수에서 분리 불가.
- **썸네일 이미지**: 클립보드 텍스트로는 안 넘어감. `i.ytimg.com`은 CORS 헤더가 없어 클라이언트 캔버스 합성도 불가 → 서버 프록시가 있어야 함.

## V. 키 확보 후 순차 검증 체크리스트 (2026-09-07 코드 선반영분)

아래는 **코드는 있으나 실제 API·브라우저로 검증하지 못한** 것들이다. 순서대로 진행하고,
통과한 항목은 지우고 실패한 항목은 B절로 옮긴다.

**0. 준비**
- [ ] `.env.local`에 `YT_API_KEY=...` (카나리 값 교체). 기존 노출 키면 측정 후 즉시 재발급(A3)
- [ ] `npm run measure -- "키워드1" "키워드2" "키워드3"` — 검색 3회 소비. 출력 저장 `measure-out/`

**1. 실측 스크립트가 알려주는 것 (판단 기준)**
- [ ] 성과배수 p50/p90 — **2배 이상 비율**이 10~30% 범위인가? 벗어나면 `OUTPERFORM_THRESHOLD` 재조정 (B4)
- [ ] 기준선 출처 — `format-median`이 다수인가? `lifetime-mean`이 많으면 `MIN_FORMAT_PEERS`(3)가 높거나 업로드 목록 회수율이 낮은 것
- [ ] 옛/새 기준선 비율 — p50이 1에서 멀거나 `>2배`·`<0.5배` 건수가 많으면 **B1 오염이 실제로 컸다는 증거**. 1 근처면 포맷 분리의 실익이 작았던 것
- [ ] 혼합 포맷 채널 비율 — 낮으면(<20%) 포맷 분리 비용(채널당 2 units)을 재고
- [ ] 업로드 목록 없음 비율 — 높으면 404 외 다른 실패 원인이 있는지 로그 확인
- [ ] 구독자 비공개·좋아요 숨김 비율 — '측정불가' 표시가 실제로 얼마나 자주 뜨는지
- [ ] 소요 시간 — 50개 검색이 Vercel 60s 안에 들어오는지(채널 30개 × 2회 순차 파도)

**2. 검색 파이프라인 (Phase 1·3 + 포맷 분리)**
- [ ] `npm run dev` → 실제 검색 → 결과 렌더. `MALFORMED_RESPONSE`가 뜨면 schema.ts와 실응답 대조
- [ ] 카드 성과배수 툴팁에 "같은 채널의 최근 롱폼 N편 중앙값 대비"가 뜨는지 / `*` 표시(lifetime) 비율
- [ ] 검색 깊이 200에서 총 소요 시간과 `otherUnits` 실측 (예상 ≤408)
- [ ] 할당량 소진 재현 불가 시: 잘못된 키로 `API_KEY_INVALID` 502 경로만 확인 (이미 확인됨)

**3. 썸네일 컨택트시트 (브라우저)**
- [ ] `/api/thumbnail?v=<실제ID>` → 200 image/jpeg, `X-Thumbnail-Variant` 헤더. maxres 없는 영상은 hq로 내려가는지
- [ ] "썸네일 시트 복사" → Chrome/Edge에서 ChatGPT·Claude 입력창에 붙여넣기 → 격자 이미지 + `#n` 라벨 보이는지
- [ ] 라벨 `#n`이 프롬프트 표의 행 번호와 일치하는지 (상위 1..N, 하위 N+1..)
- [ ] Safari/Firefox — `ClipboardItem` 미지원이면 PNG 다운로드로 떨어지고 문구가 "이미지 내려받음"인지
- [ ] 캔버스 오염 없음 (콘솔에 SecurityError 없음). 있으면 프록시가 안 타는 경로가 있는 것

**4. 자막 붙여넣기 (브라우저)**
- [ ] 카드 '자막' 토글 → 입력란 → YouTube '스크립트 표시'에서 복사·붙여넣기 → 'AI분석' 복사 → 프롬프트에 `## 자막` 섹션과 5번 요청이 들어가는지
- [ ] 12,000자 넘는 자막에서 "앞 12,000자만 포함" 문구
- [ ] 카드 링크 오버레이 위에서 textarea 클릭·입력이 되는지(z-10)

**5. 프롬프트 실효성 (LLM에 실제로 붙여넣기)**
- [ ] 시장 분석 프롬프트 + 썸네일 시트를 Claude/ChatGPT에 넣어 출력 확인: 행 번호 근거를 다는지, "데이터 없음"을 지어내기로 메우지 않는지
- [ ] 자막 포함 단건 프롬프트: 대본 구조 항목이 자막 문장을 인용하는지
