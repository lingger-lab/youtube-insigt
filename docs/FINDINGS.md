## 반복해서 배운 것 (규칙이 된 것)

1. **합성 데이터 위의 설계 판단은 판단이 아니다.** 실측 전 3개 가설(F14·F15·"검색 3회 원인") 모두 틀리거나 부분 정답이었다.
2. **1차 보고를 그대로 두지 않는다.** F7·F14·F19처럼 틀린 보고는 정정 커밋과 이 문서에 남긴다.
3. **셀 수 있는 것은 앱이 센다.** 글자수·중앙값·포맷을 모델에게 맡기면 거부하거나 틀린다(F29).
4. **없다고 선언하기 전에 정식 경로를 다시 찾는다.** "자막 불가"는 2일 뒤 Gemini 경로로 뒤집혔다(F32). 단 비정식 경로는 정책으로 막혀 있다(F31).
5. **문서는 코드와 같은 커밋.** 안 그러면 한 세대 뒤처진 거짓 문장이 남는다(F22).
6. **출력물을 지키면서 정직성을 넣는다.** 지어내기를 막다 시안 자체를 없앤 것(F24)이 이번 세션의 가장 큰 과잉 교정이었다.
